# WellNet — illustrations with gray accent shapes

Eight treatment illustrations with organic gray shapes inspired by the supplied reference. The fine artwork from the corrected set is retained.

## Contents

- **svg/** — complete vector illustrations. `accent-blobs` is the separate lower layer, and `original-artwork` contains the unchanged detailed paths.
- **png-1254/** — transparent 1254 × 1254 PNGs composited from the original generated artwork and the new vector accents.
- **png-512/** and **png-48/** — transparent PNGs exported directly from the finished composition.
- **accent-layers/** — the two gray shapes by themselves, on the same square canvas, for independent editing.
- **wellnet-overview.png / .svg** — previews in the order listed below.

The accent palette uses **#E4E4E4** and **#CACACA**. To apply brand colors, change the `fill` attributes of `accent-light` and `accent-medium` in each SVG. The canvas outside the artwork and accent shapes remains transparent.

The original artwork paths were verified unchanged. All fully opaque pixels in the original PNG illustration remain unchanged in the final 1254 px composition. Antialiased edges blend naturally with the new shapes behind them.
