01

מתכוננים

בערך עשרים דקות. עשו את זה היום, ומחר רק פותחים את המחשב ומתחילים.

כל צעד נגמר בבדיקה, כדי שתדעו שזה עבד. את הפקודות מריצים ב־Terminal (Applications ← Utilities ← Terminal): מעתיקים, מדביקים ולוחצים Enter.

  1. התקינו את Node.js

    הורידו את גרסת ה־LTS מהאתר nodejs.org (גרסה 22.12 ומעלה) והתקינו עם הגדרות ברירת המחדל. אחר כך פתחו חלון Terminal חדש, העתיקו את הפקודה, הדביקו ולחצו Enter:

    node -v

    בדיקה: מופיע v22.12 או גרסה גבוהה יותר.

  2. התקינו את Git

    העתיקו את הפקודה, הדביקו ב־Terminal ולחצו Enter. אם נפתח חלון שמציע להתקין את command line developer tools, לחצו Install, חכו שההתקנה תסתיים, והריצו את הפקודה שוב.

    git --version

    בדיקה: מופיעה גרסה, למשל git version 2.4x.

  3. הכינו את Chrome

    התקינו או עדכנו את Google Chrome. ב־Chrome פתחו Settings ← System, הפעילו את Use graphics acceleration when available, והפעילו את Chrome מחדש.

    בדיקה: הקלידו chrome://gpu בשורת הכתובת. ליד WebGL2 צריך להיות כתוב Hardware accelerated.

  4. קבלו גישה לסדנה

    תקבלו במייל הזמנה ל־Bitbucket של זמינגו. אשרו אותה והתחברו (עם חשבון Atlassian, או צרו חשבון חדש).

    אחר כך צרו מפתח שמאפשר למחשב שלכם להוריד את הסדנה, API token:

    Bitbucket ← התמונה שלכם (למעלה בפינה) ← Account settings ← Security ← Create and manage API tokens ← Create API token with scopes

    תנו לו את השם daring, קבעו שיפוג אחרי הסדנה, בחרו באפליקציה Bitbucket, סמנו את ההרשאה read:repository ולחצו Create token. שמרו את המפתח במקום בטוח: הוא מוצג רק פעם אחת.

    בדיקה: הכתובת bitbucket.org/zemingo/daring-workshop נפתחת כשאתם מחוברים.

  5. הורידו את הסדנה

    1. פתחו את Terminal. העתיקו את הפקודה, הדביקו אותה ולחצו Enter:

    cd ~ && git clone https://bitbucket.org/zemingo/daring-workshop.git daring && cd daring

    2. הטרמינל מבקש Username. העתיקו את זה, הדביקו ולחצו Enter:

    x-bitbucket-api-token-auth

    3. הטרמינל מבקש Password. הדביקו את ה־API token שיצרתם בצעד 4 ולחצו Enter. לא תראו כלום בזמן ההדבקה, וזה תקין.

    זה מוריד את כל תשעת האתגרים לתיקייה חדשה בשם daring. עושים את זה רק פעם אחת.

    בדיקה: אין הודעת שגיאה, ובשורה שבה מקלידים מופיע עכשיו daring.

  6. מתקינים הכל ובודקים

    מתוך התיקייה daring. הפקודה הראשונה צריכה אינטרנט פעם אחת (דקה או שתיים); אחרי זה הכל עובד גם בלי אינטרנט. העתיקו כל פקודה, הדביקו ולחצו Enter:

    npm run setup
    npm run check

    בדיקה: בשורה האחרונה כתוב ✓ Ready. ליד כל דבר שמסומן ב־✗ כתוב בדיוק איך לתקן.

  7. נסיעת מבחן

    לכל אתגר יש פרויקט פתיחה קטן שכבר רץ. נסו אחד: העתיקו, הדביקו ב־Terminal ולחצו Enter.

    cd ~/daring/starters/09-loom && npm run dev

    פתחו ב־Chrome את הכתובת שמופיעה (http://localhost:5173) ולחצו Start. כדי לעצור, לחצו Ctrl + C ב־Terminal.

    בדיקה: משהו מתחיל לצמוח על המסך.

  8. חברו את עוזר ה־AI שלכם

    התחברו לעוזר שאתם רגילים לכתוב איתו קוד, ופתחו בו את התיקייה daring. אחר כך שאלו אותו:

    "בקובץ starters/09-loom/src/config.js, מה אפשר לשנות?"

    בדיקה: הוא עונה על ההגדרות בקובץ. הוא רואה את הקבצים שלכם, כלומר אתם מחוברים.

    אם אתם עובדים עם כלי תמונה שיודע להרחיב תמונה: ChatGPT או Gemini, או Generative Expand בפוטושופ, התחברו גם אליו. אחת התחנות עשויה להזדקק לו.

  9. תנו ל־Chrome להשתמש במצלמה ובמיקרופון

    חלק מהאתגרים מקשיבים או מסתכלים. לחצו על הכפתור, וכש־Chrome שואל, לחצו Allow. שום דבר לא מוקלט ולא נשלח: זה רק מראה לכם מה Chrome רואה ושומע.

    אם Chrome מציג שגיאה, או שהתמונה נשארת שחורה: פתחו System Settings ← Privacy & Security ← Camera, ואחר כך Microphone, והפעילו את Google Chrome. סגרו את Chrome לגמרי (⌘ Q), פתחו אותו שוב ונסו שוב.

    בדיקה: אתם רואים את עצמכם, והפס זז כשאתם מדברים.

  10. מחר בבוקר, לפני 10:00

    עדכנו לגרסה האחרונה. זה מביא גם את דף הסדנה עם הבריפים. העתיקו, הדביקו ב־Terminal ולחצו Enter:

    cd ~/daring && git pull && npm run setup && npm run check

    תביאו את המחשב טעון, את המטען, ואוזניות חוטיות אם יש לכם.

    בדיקה: בשורה האחרונה עדיין כתוב ✓ Ready.
